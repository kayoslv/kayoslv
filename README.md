### 🌙 Projeto em Destaque: [Moons Framework](https://github.com/KAYOGS/Moons)

> *"Simple as a script. Fast as a binary."*

Ecossistema próprio construído com **Lua** e **Pallene**, desenhado para operar com alta performance e baixo consumo de recursos em cenários de escassez de hardware. 
* Combina a simplicidade de scripts em Lua com a tipagem estática e compilação Ahead-of-Time (AOT) do Pallene para mitigar gargalos de memória.
* Roda como um daemon em ambiente **Docker** isolado e *zero-config*, valorizando tecnologias core criadas no Brasil (PUC-Rio).
